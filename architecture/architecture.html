3 · Data cleaning lab — Sale Report

The raw "Orders by Item" file is messy: a title block, headers, order lines, item totals and grand totals. app/importers/orders.py keeps only the order lines, copies item Description and Pack from the item-total row, and builds the new Dv+SaleReport key. Step through it.

4 · Database — how tables are generated

There is no hand-written SQL schema per table. app/importers/specs.py is the single registry: each entry gives the SQLite columns and the viewer columns. At startup init_schema() creates missing tables and adds missing columns, never dropping data. Row counts below are a snapshot of your current database.

Life of one file's rows

5 · Recheck engine — 30 protocols

A filled Credit Memo Batch (.xlsx) is read with openpyxl and compared with the template, the Ageing, the Sale Report and Report 2 that are already in SQLite. Nothing is written back. Press Run to watch every protocol inspect the batch.

Why it is fast now: the Ageing / Sale Report / Report 2 lookup tables are loaded once and kept in memory until the database file changes (an import or edit). Template column widths are measured once per sheet instead of thousands of times.
